**Что реализовано**
- Вход по `idInstance` и `apiTokenInstance`, перед входом проверяется, что инстанс авторизован (`getStateInstance`).
- Создание нового чата по номеру телефона получателя с предварительной проверкой номера (`checkWhatsapp`).
- Отправка текстовых сообщений методом SendMessage.
- Получение ответов методом HTTP API: цикл `receiveNotification` → обработка → `deleteNotification`. Ответ появляется в чате автоматически.
- Интерфейс в стиле web.max.ru: список чатов слева, переписка справа, адаптивная вёрстка для телефона.
- На экранах есть подсказки, где взять данные и что делать дальше.
- Unit-тесты (vitest), TypeScript, архитектура Feature-Sliced Design.

**Стек:** React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui, axios, TanStack Query, zustand, react-hook-form + zod.

**Важное замечание про мессенджер.** Задание выполнено для WhatsApp, а не для MAX: в консоли GREEN-API мне был доступен только тариф для WhatsApp и Telegram, а ТЗ допускает такой вариант. Методы отправки и получения (`sendMessage`, `receiveNotification`, `deleteNotification`) у MAX и WhatsApp одинаковые, отличается проверка номера (`checkWhatsapp` вместо `checkAccount`), поэтому перенос на MAX потребует правки в одном месте: `src/shared/api/green.ts` и форме создания чата.

**Как проверить**
1. В консоли GREEN-API убедитесь, что инстанс авторизован, `incomingWebhook` включён, а поле адреса уведомлений (URL) пустое.
2. Откройте https://green-api-tz-blue.vercel.app и введите свои `idInstance` и `apiTokenInstance`. Токен хранится только в браузере и никуда, кроме GREEN-API, не отправляется.
3. Введите номер получателя с кодом страны (например, 77001234567), нажмите «Чат», отправьте сообщение.
4. Ответьте с телефона получателя: ответ появится в чате в течение нескольких секунд.
